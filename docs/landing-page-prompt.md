## پرامپت

یک لندینگ پیج مدرن، تکصفحهای و تکفایلی برای محصول **Atlas** بساز — یک دستیار هوشمند محلی (Local AI Agent) برای دسکتاپ لینوکس که کاملاً روی دستگاه کاربر اجرا میشود و هیچ دادهای از ماشین خارج نمیشود.

### هویت بصری
- سبک: **گلس‌مورفیسم شیشه‌ای** با عمق، بلور پسزمینه (backdrop-blur)، حاشیههای نیمهشفاه و گرادیانهای نرم
- تم پیشفرض «نیمهشب» (Midnight): پسزمینه تیرهٔ سرمهای `#05060a` → گرادیان اکسنت نیلی `#4f46e5 → #a5b4fc`
- جهت صفحه: **RTL فارسی کامل**، فونت Vazirmatn (از CDN)، متنها فارسی؛ اصطلاحات فنی انگلیسی
- یک «گوی Atlas» متحرک در هیرو: کرهٔ شیشهای درخشان با حلقههای چرخان دور آن (CSS animation خالص، بدون تصویر)

### بخشها (بهترتیب)
1. **نوبار شیشهای چسبان**: لوگو 🧭 Atlas + لینکها (امکانات، مهارتها، دانلود) + دکمهٔ CTA
2. **هیرو**: تیتر بزرگ «دستیار هوشمندت، روی دستگاه خودت.» + زیرتیتر دربارهٔ حریم خصوصی محلی + دو دکمه: «⬇️ دانلود AppImage» (اصلی، گرادیانی) و «مشاهده در گیت‌هاب» (ثانویه) + گوی متحرک کنار متن
3. **نوار ویژگیها** (۴ کارت شیشه‌ای با آیکون): 🔒 کاملاً محلی و خصوصی · 💬 چت استریمی واقعی · 🧩 فروشگاه مهارتها · 🎨 ۸ تم شیشه‌ای
4. **بخش مهارتها**: توضیح کوتاه فروشگاه skills.sh با ماکآپ ساختگی چند کارت مهارت
5. **بخش تمها**: ردیف ۸ دایرهٔ گرادیانی پیشنمایش تمها (نیمهشب، شفق، غروب، اقیانوس، جنگل، کاغذی، لاوندری، رز) با قابلیت هاور
6. **CTA پایانی**: کارت شیشه‌ای بزرگ «همین حالا Atlas را داشته باش» + دکمهٔ دانلود
7. **فوتر**: ساختهشده با 🧡 توسط [alavi8940-tech](https://github.com/alavi8940-tech) + لینک ریپوی خصوصی `alavi8940-tech/Atlas-v4`

### الزامات فنی
- تکفایل HTML با Tailwind CDN یا CSS خالص — بدون وابستگی build
- انیمیشنها فقط CSS (fade-in هنگام اسکرول با IntersectionObserver سبک)
- ریسپانسیو کامل موبایل → دسکتاپ
- بدون تصویر خارجی؛ همهٔ المانهای گرافیکی CSS/SVG باشند
- لهجهٔ بصری: گوشههای خیلی گرد (`border-radius ≥ 1.25rem`)، سایههای رنگی نرم، افکت شاین ظریف روی دکمهٔ اصلی
